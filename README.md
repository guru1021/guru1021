🤖 GuruBot

GuruBot is a simple multi-agent AI chatbot built in Python. It can:
	•	Answer questions from a text file 📄
	•	Detect objects in an image file 🖼️ (mocked for now)
	•	Handle small talk like greetings and farewells 👋

⸻

🚀 Features
	1.	TextAgent
	•	Upload .txt files.
	•	Ask questions, and it will search for relevant lines.
	2.	ImageAgent
	•	Upload .png, .jpg, or .jpeg files.
	•	Pretends to detect objects in the image (future-ready for real image AI).
	3.	GuruBot Manager
	•	Switch easily between TextAgent and ImageAgent.
	•	Upload files and chat in one console.
	•	Handles greetings (hi, hello) and farewells (bye).

⸻

📝 Commands

Inside the chat:
	•	switch text → Switch to TextAgent.
	•	switch image → Switch to ImageAgent.
	•	upload filename.txt → Upload a text file.
	•	upload filename.jpg → Upload an image file.
	•	bye → Exit the bot.
